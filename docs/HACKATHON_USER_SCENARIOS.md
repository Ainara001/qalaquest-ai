# Тестовые сценарии QalaQuest AI (для жюри)

Формат по ТЗ: вход → ожидаемый тип ответа → что показывает приложение. Все сценарии выполняются в настоящем приложении (карта, строка поиска или вкладка «AI-гид»), на реальных POI Астаны из OpenStreetMap.

Статус проверки:
- **Gemini** — проверен с реальным ключом (разбор запроса RU/KK и генерация);
- **UI** — проверен на тестовом стенде с настоящим кодом бэкенда;
- **Реальная БД** (1030 POI) — подтверждена на этапах 2–5. Повторный прогон этапов 6–7 на ней выполняется командой из README (см. [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md)).

| # | Вход | Ожидаемый тип ответа | Как это делает приложение |
|---|---|---|---|
| 1 | «Я возле MEGA Silk Way, хочу прогуляться 30–60 минут — что посоветуете?» | 1–3 места рядом с MEGA Silk Way, у каждого: почему, сколько идти, сколько там провести, что сделать | Gemini извлекает `start_place = MEGA Silk Way`, `time = 60` (проверено с реальным ключом). Старт берётся из реального POI. Фильтр «дойти + посмотреть ≤ времени». Карточки с причиной и «Идея · AI». Кнопка «Начать прогулку» строит маршрут по реальным дорожкам |
| 2 | «Хочу тихое место с кофе и розеткой недалеко» | Кафе рядом и честное «о розетках и тишине данных нет» | Gemini: `include_categories = cafe`, `atmosphere = quiet` (проверено). Карточки кафе с часами «открыто / закрыто / не подтверждено». Уведомление «В данных нет сведений: розетки, тишина — уточните на месте» (проверено с реальным Gemini) |
| 3 | «Еду с ребёнком — где рядом детские площадки или музей с интерактивами?» (или чип «С детьми») | Площадки, парки, музеи; никаких выдуманных «интерактивов» | Флаг «с детьми» и семейные категории. Казахская версия «Баламмен бармын…» распознаётся (проверено). Про «интерактивы» — только если это есть в описании OSM |
| 4 | «Я турист, у меня 2 часа перед вылетом: что посмотреть поблизости?» | Короткий маршрут, который укладывается в 120 минут | Якорь по названию (например, аэропорт или вокзал, если есть в базе). Время 120. Планировщик Valhalla отбрасывает варианты дольше бюджета и честно пишет, если ничего не помещается |
| 5 | «Ищу необычную ночную активность (последние пару часов)» | Места, открытые ночью по часам из OSM; без выдуманных вечеринок | Часы работы разбираются по времени Астаны: закрытые к приходу понижаются, у каждого места статус «открыто / закрыто / часы не подтверждены». Слоя событий пока нет — приложение не выдумывает мероприятия |
| 6 | Чип «Поесть» / «Кофе» на карте | Реальные кафе и рестораны на карте и в «Местах для вас» | Без LLM: фильтр по категориям базы, карточки с часами и источником |
| 7 | Настроение «Фото» → «Спокойно» | Разные места на карте | Пересчёт ранжирования. Проверено: «Фото» → архитектура и памятники, «Спокойно» → парки и прогулочные зоны |
| 8 | Чип «Доступно» / «Я на коляске» | Только места с `wheelchair=yes` в OSM; путь «не проверен» | Фильтр по тегу, отдельные статусы «вход» и «путь», предупреждение в маршруте |
| 9 | «Начать прогулку» → «Осталось 20 минут» | Новый маршрут после подтверждения | Living Route показывает предложение, текущий маршрут не меняется до «Применить» |
| 10 | Переключение RU ↔ ҚАЗ | Интерфейс и ответы AI на выбранном языке, без потери результата | Проверено: настроение, карточка, маршрут сохраняются |

## Пример ответа (сценарий 2, реальный Gemini, тестовые POI)

> «Вот кофейни, найденные по вашему запросу неподалёку.»
> 1. **Кафе** · 1,7 км по прямой · *Закрыто сейчас* (Mo-Su 10:00-20:00).
>    Почему: «Место входит в категорию „Кафе и кофейни“ и находится в 1654 метрах по прямой; в источнике указаны часы работы Mo-Su 10:00-20:00».
>    Идея · AI: «Загляните за порцией кофе, ориентируясь на график работы».
> ⓘ В данных нет сведений о том, что вы просили: розетки, тишина. Места подобраны по типу и расстоянию — уточните на месте.

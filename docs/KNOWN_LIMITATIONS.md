# Известные ограничения (честно)

## Не проверено
- Этапы 6–7 не прогонялись на машине с Docker и реальной БД (1030 POI). Проверены автотестами (56), реальным ключом Gemini и в интерфейсе на тестовом стенде с настоящим кодом бэкенда. Новый SQL поиска по названию (`/api/pois/suggest`) скомпилирован, но на PostgreSQL не выполнялся.
- Настоящие телефоны (iPhone Safari / Android Chrome) и экранная клавиатура проверены только в эмуляции 320–430 px.

## Данные
- В OSM мало часов работы, цен, телефонов, описаний и тегов доступности. Многие места подбираются по категории и расстоянию.
- Разбирается только распространённый формат `opening_hours`. Праздники, сезонные правила, «sunrise» → «часы не подтверждены».
- Рейтингов и популярности нет: правомерного источника нет.
- Доступность: используется только тег `wheelchair` и связанные теги самого места. Отдельные объекты OSM (входы, пандусы, бордюры, ступени) пока не импортируются. Значков пандусов на карте нет. Путь для коляски всегда «не проверен на безбарьерность».
- Фото не показываются: нет источника с подходящей лицензией.

## Не реализовано
- **Наполнение событий:** заготовка слоя готова (таблица, импорт iCal, API, фильтры, иконки), но ни один источник не подключён — нет подтверждённого законного источника. Мероприятия не выдумываются. Как подключить: [LOCAL_EVENTS_SOURCES.md](LOCAL_EVENTS_SOURCES.md). Миграция `0004` на реальной БД не применялась (здесь нет PostgreSQL).
- Импорт отдельных объектов доступности и проверка пути по сегментам: [ACCESSIBILITY_DATA_AND_LIMITS.md](ACCESSIBILITY_DATA_AND_LIMITS.md).
- Презентация (PPTX/PDF) и видео на YouTube — есть только сценарии ([PITCH_5_7_MIN.md](PITCH_5_7_MIN.md), [VIDEO_CAPTURE_GUIDE.md](VIDEO_CAPTURE_GUIDE.md)).

## Технические
- Онлайн-демо на Render (бесплатный тариф): поиск без векторов (лексический режим: 512 МБ RAM не вмещают модель эмбеддингов, а суточная квота Gemini-эмбеддингов — 1000 текстов), генерация на `gemini-flash-lite-latest` (у `gemini-flash` на бесплатном ключе 20 запросов в сутки), нет Valhalla (оценки по прямой), сон после 15 мин простоя. Подробно: [DEPLOY_RENDER.md](DEPLOY_RENDER.md).
- Бесплатный ключ Gemini ограничен по запросам в минуту. При частых запросах будет «AI-сервис перегружен, повторите через минуту». Один ответ чата — это 2 вызова Gemini, по 4–7 секунд каждый.
- `gemini-2.5-flash` недоступна новым ключам → используется `GEMINI_MODEL=gemini-flash-latest` (сейчас это `gemini-3.8-flash`).
- Ограничитель частоты, сессии чата и кэш — в памяти одного процесса (для демо достаточно).
- Образ Valhalla `latest` не закреплён по версии.

# UX: было → стало и главные пути пользователя

| Было (этап 5) | Стало (этапы 6–7) |
|---|---|
| 4 вкладки: Главная, Карта, AI-гид, Профиль; карта — отдельный экран | 3 вкладки; **карта — стартовый экран** |
| Приветствие, баннеры, карточки на «Главной» | Только карта, строка поиска и одна строка чипов |
| Поиск = фильтр названий на карте; AI — в отдельной вкладке | Одна строка «Место, еда или спросить AI»: название ищется в базе без AI, просьба словами идёт в AI, ответ на карте |
| Еду и кофе искать через категории | Чипы **Поесть · Кофе · Погулять · С детьми · Доступно**, затем Настроение, Рядом, Время, Бюджет |
| Настроение только на «Главной», запускало чат | Настроение одним нажатием меняет места на карте |
| Маршрут на отдельной странице `/walk` | Маршрут и прогулка в той же нижней панели над картой |
| Часы работы — только текст | «Открыто / закрыто / часы не подтверждены» |

## Главные пути
1. **Найти место:** открыть приложение → «Кофе» (или «Настроение») → нажать метку → карточка → «Маршрут».
2. **Спросить AI:** ввести «хочу погулять час бесплатно» → 1–3 места с «почему» → «Начать прогулку».
3. **Изменить прогулку:** полоса активной прогулки → «Изменить маршрут» → условие → «Применить».

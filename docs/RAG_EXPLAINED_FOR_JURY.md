# Как работает RAG в QalaQuest AI (на одной странице)

```
OpenStreetMap ──автоимпорт──► база POI Астаны (1030 мест) ──► векторный индекс (e5, RU/KK/EN)
                                                                    │
запрос пользователя ──► 1. Понимание (Gemini) ──► 2. Поиск в базе ──► 3. Фильтры и ранжирование
                                                                    │
                                 6. Ответ на карте ◄── 5. Проверка ◄── 4. Gemini объясняет выбор
```

1. **Понимание запроса.** Gemini превращает текст в структуру: где человек, сколько у него времени, бюджет, интересы, исключения («не хочу музеи»), дети, доступность. Название места («MEGA Silk Way») находится в нашей базе, а не выдумывается. Простой поиск по названию идёт вообще без AI.
2. **Поиск (Retrieval).** PostgreSQL + PostGIS + pgvector: места в радиусе, который успеваешь пройти, плюс смысловое сходство с запросом и по-настоящему совпадающие теги OSM.
3. **Фильтры и ранжирование.** Сначала жёсткие ограничения: время, доступность, «только подтверждённо бесплатно», «больше не показывать». Затем понятная оценка по 9 сигналам: смысл, интересы, расстояние, время, бюджет, контекст, отзывы пользователя, полнота данных, погода. Закрытые к приходу места понижаются. Настроение меняет вес интересов.
4. **Генерация.** Gemini получает до 8 реальных кандидатов и выбирает 1–3 по их ID. Он пишет только «почему подходит» и «идея, что сделать».
5. **Проверка на сервере.** ID только из кандидатов. Время, цены, рейтинги и «открыто сейчас», которых нет в фактах, вырезаются. Описания мест считаются данными, а не инструкциями: это защита от prompt injection.
6. **Ответ.** Карточка собирается из базы: название, расстояние, время пути (оценка), время посещения (оценка по типу места), часы «открыто / закрыто / не подтверждено», доступность входа отдельно от пути, источник OSM с датой. Текст AI помечен как «AI». Карта показывает те же 1–3 места.

**Чем это лучше обычной карты:** учитываются намерение, настроение, время, погода и доступность, и каждая рекомендация объясняет «почему».

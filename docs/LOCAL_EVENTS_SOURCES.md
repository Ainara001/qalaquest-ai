# Местные события: источники и статус

**Статус: заготовка готова, источники не подключены.** Есть таблица `events` (миграция `0004`), конвейер импорта iCal (`python -m app.scripts.import_events`), API `GET /api/events` (`when=today|evening|tomorrow|weekend|upcoming`, `category`, координаты), чип «События» на карте, фильтры, иконки по типу события и маркеры только для площадок, найденных среди реальных POI. `EVENT_SOURCES` по умолчанию пуст: ни один источник не проверен на законность автоматического сбора. Поэтому приложение честно показывает «Источники событий пока не подключены» и ничего не выдумывает.

**Как подключить источник** (после проверки условий использования и robots.txt):
```bash
# .env
EVENT_SOURCES=[{"name":"Название площадки","type":"ical","url":"https://…/events.ics","terms":"публичный iCal, повторное использование разрешено"}]
docker compose exec backend python -m app.scripts.import_events
```
Площадка (`LOCATION`) сопоставляется с POI по названию. Без совпадения — статус `place_unconfirmed`, событие не ставится на карту. Событие только с датой (без времени) — `time_unconfirmed`.

## Какие источники допустимы (кандидаты, требуют проверки условий использования)
- Официальные сайты площадок с разметкой Schema.org/Event или открытым RSS/iCal (театры, филармония, музеи, Astana Opera и др.).
- Открытые публичные API городских порталов и акимата, если они разрешают повторное использование.
- Агрегаторы билетов — **только по договору или разрешённому API**; обходить запреты на автоматический сбор (robots.txt, условия) нельзя.

## Схема (когда источник будет подтверждён)
`events`: title, category (exhibition / music / party / theatre / other), venue, poi_id или координаты, start_at, end_at (время Астаны, UTC+5), source_url, organizer, description, price (только подтверждённая), age_limit, last_checked_at, verification_status.
- ETL отдельный от POI, по расписанию. Дедупликация по площадке + дате/времени + названию/URL.
- Истёкшие события скрываются. Событие без подтверждённого времени или места не подаётся как «идёт сейчас».
- UI: свои иконки (картина, нота, маски, символ праздника), фильтры «Сегодня / Завтра / Выходные / Вечером», карточка с источником и кнопкой «Маршрут». Поиск — RAG по реальным записям `events` с проверкой времени.

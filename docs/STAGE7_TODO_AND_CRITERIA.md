## 4. Рекомендованный порядок при дедлайне сегодня

1. Поднять стек и импортировать данные (п. 1–2) — без этого нет демо и видео.
2. Чипы «Поесть/Кофе/…» и новые названия настроений (п. 3–4) — 1 час.
3. Часы работы «открыто/закрыто/не подтверждено» (п. 5) — 1–2 часа.
4. Минимальный режим доступности: статус входа по тегу + маркировка маршрута «не проверен» (часть п. 6) — 1–2 часа.
5. Презентация, документ сценариев, запись видео (п. 16–18).
6. События — только каркас + честная пометка, если останется время.

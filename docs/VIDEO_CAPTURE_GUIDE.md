# Как записать демо-видео (3–5 минут)

**Подготовка**
1. `.env`: `POSTGRES_PASSWORD`, `GEMINI_API_KEY`, `GEMINI_MODEL=gemini-flash-latest`.
2. `./routing/prepare.sh` → `docker compose up -d --build`. Подождать, пока `GET /api/routes/status` вернёт `available: true` (около 10 минут при первом запуске).
3. Загрузить данные: `docker compose exec backend python -m app.scripts.import_pois --index`.
4. Браузер Chrome → DevTools → режим телефона 390×844 (или запись экрана телефона в той же сети). Включить русский язык и светлую тему.
5. Между AI-запросами делать паузу 10–15 секунд: бесплатный ключ Gemini ограничен по запросам в минуту.

**Последовательность кадров**
1. 0:00 — открыта карта Астаны. Показать строку поиска и чипы «Поесть, Кофе, Погулять, С детьми, Доступно».
2. 0:15 — нажать «Кофе»: реальные кафе на карте, у каждого статус часов.
3. 0:35 — «Настроение» → «Красивые фото», затем «Спокойно»: на карте другой набор мест и причины.
4. 1:00 — в поиск: «Я возле MEGA Silk Way, у меня 60 минут, хочу бесплатно». Показать ответ AI, «Почему», «Идея · AI», источник.
5. 1:40 — «Начать прогулку по этим местам»: линия маршрута, время, расстояние → «Начать».
6. 2:10 — «Изменить маршрут» → «Осталось 20 минут» → предложение → «Применить».
7. 2:40 — «Тихое кафе с розеткой» → уведомление «о розетках данных нет».
8. 3:00 — «Доступно»: карточка места, вход «подтверждено в OSM», путь «не проверен».
9. 3:20 — «Удиви меня» → «Другой вариант». «Квест» → «Фотоохота». «Для компании» с тремя участниками.
10. 3:50 — переключить на ҚАЗ. Профиль → «Как работает AI и откуда данные».

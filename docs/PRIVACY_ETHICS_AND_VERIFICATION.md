# Приватность, этика и проверка информации

## Что собираем и где храним

| Данные | Зачем | Где | Срок | Как удалить |
|---|---|---|---|---|
| Геолокация | Подбор мест рядом, маршрут | Только память вкладки; запрашивается **только по нажатию**; можно выбрать точку на карте вручную | До закрытия вкладки. На сервере не хранится, в журналы не пишется | Закрыть вкладку / «По всему городу» |
| Координаты в запросе | Расчёт расстояний и маршрута | Наш сервер (в памяти на время запроса), Open-Meteo (округлённо до ~5 км), свой маршрутизатор Valhalla | Не сохраняются | — |
| Текст запроса | Понимание запроса | Gemini (Google) — только текст и факты о кандидатах, **без координат пользователя** | Сессия диалога в памяти сервера, 2 часа | «Новый диалог», «Удалить все мои данные» |
| Профиль, отметки | Персональные рекомендации | Только это устройство (`localStorage`) **и только если включено «Сохранять на устройстве»** | Пока пользователь не удалит | Профиль → «Сбросить», «Удалить все мои данные» |
| Прогулка, квест, участники группы | Текущая прогулка | `sessionStorage` вкладки | До закрытия вкладки | «Завершить» |

Без регистрации и аккаунтов. Без фонового отслеживания. Нет идентификации по IP или отпечатку браузера. Журналы сервера содержат только путь, статус и время ответа.

## Как проверяем информацию

| Объект | Чем подтверждается | Если данных нет или они устарели |
|---|---|---|
| POI и координаты | OSM `osm_type/osm_id`, `source_url`, дата снимка OSM (`source_updated_at`), журнал импорта `import_runs` | Объект не создаём. Удалённые в OSM находятся по `last_seen_at` |
| Часы работы / контакты | Теги OSM `opening_hours`, `phone`, `website` | «Часы не подтверждены». «Открыто/закрыто» — только если формат разобран. Сложные форматы → «не подтверждено» |
| Рейтинг / популярность | Правомерного источника нет | Всегда «нет данных». Звёзды не показываем |
| Пандус / доступный вход | Теги OSM `wheelchair`, `ramp*`, `wheelchair:description` | «Доступность не подтверждена». Вход и путь — отдельно |
| Маршрут | Valhalla по графу OSM (для коляски — профиль wheelchair) | Если маршрутизатор недоступен — расстояние по прямой с пометкой «это не навигация», линия не рисуется. Путь для коляски — «не проверен на безбарьерность» |
| Событие | Слой событий не подключён (нет проверенного законного источника) | Мероприятия не показываем и не выдумываем |
| AI-текст | Выбор только из ID найденных мест + серверная проверка | Текст с выдуманными временем, ценой, рейтингом или «открыто сейчас» удаляется. Факты и «Идея · AI» разделены |
| «Тихо», «розетка», «уютно», «малолюдно» | Таких атрибутов в данных нет | Явное уведомление «нет сведений — уточните на месте» |

Независимой проверки мест на месте не проводилось. Достоверность ограничена данными OpenStreetMap.

## Безопасность сервиса
- Ограничение частоты: 12 AI-запросов в минуту с IP; поиск — 60 в минуту; маршруты — 30 в минуту.
- Одинаковые запросы, поступившие одновременно, обрабатываются один раз.
- Строгая валидация всех входов через Pydantic (неизвестные поля → 422); проверка координат (не дальше 40 км от Астаны).
- CORS только для своего фронтенда.
- Ключ Gemini только в `.env`, файл не попадает в git.
- Мы не обещаем безопасность маршрутов: на картах есть пометка о неполноте данных.
